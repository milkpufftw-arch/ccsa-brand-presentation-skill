# CCSA 品牌簡報製作 Skill

將社福機構的計畫書、成果報告與研究資料，轉換成符合 CCSA 品牌規範的簡報企劃。

## 核心功能

- 文件分析與逐頁簡報企劃
- CCSA 品牌視覺與資訊圖表設計
- 成果數據視覺化與品質檢核
- 確認企劃後製作可編輯簡報
- 社工與兒少資料倫理檢核

## 使用方法

下載本儲存庫，將 Skill 資料夾匯入支援 Skills 的 AI 工具。實際簡報產製需要相應工具及權限。
